## 依赖自动安装（当日完成）
- `app.py` 新增自检块：`asr_deps_missing()`（只用 `importlib.util.find_spec`，不导入）、
  `start_asr_deps_check()`（幂等，`_ASR_DEPS_STARTED` 防重入）、`_asr_deps_worker()`（后台线程
  用 `sys.executable -m pip install` 装，装完 `importlib.invalidate_caches()`）、`wait_asr_deps()`。
- 触发点做成**模块级**调用（不是只在 `__main__`），这样 `python app.py` / `flask run` / gunicorn
  都能生效；预热线程改为先 `wait_asr_deps()` 再加载模型。
- 状态机：unknown / present / installing / installed / failed / missing / disabled，
  经 `/api/asr/status` 的 `deps` 字段暴露。前端 `pollDeps()` 每 5 秒轮询，装好后自动把
  `btn.onclick` 从 onlineClick 切回 localClick。
- 环境变量 `ASR_AUTO_INSTALL=0` 关闭自动安装（离线/内网场景）。
- 验证：正常环境 state=present 不动手；模拟缺失 cowsay → installed 且可导入；
  不存在的包 → failed 且只打印不抛异常；ASR_AUTO_INSTALL=0 → missing 不装；
  ASR_MODE=off → disabled。浏览器端到端仍正常（识别出样例文本）。
